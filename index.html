🌾 CropYield — Crop Yield Predictor

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A ridge regression model trained on 600 synthetic farm seasons predicts crop yield in quintals per hectare. 5-fold CV: R² = 0.844, MAE = 2.50 q/ha vs a 6.45 q/ha mean-guess baseline.

How it works: each input is standardised with the training means and standard deviations, then multiplied by the model's learned coefficients. The exact same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model to within 0.01 q/ha.

Model: Ridge regression (α = 1.0) on standardised features — rainfall, average temperature, fertilizer, soil pH, irrigation. Try a sample: 1000 mm rain, 24°C, 250 kg/ha fertilizer, pH 6.8, irrigated → about 48.3 q/ha.
